# Session End Prompt

Before ending this work session:

1. Verify the code or result with relevant tests/checks where possible.
2. Update the active task with verified results and next action.
3. Update `.ai/current.md` only if global project state changed.
4. Append meaningful semantic changes to `.ai/changelog.md`.
5. Create/update a handoff if unfinished work must continue in another session.
6. Add or supersede an ADR only if a durable technical decision changed.
7. Do not mechanically rewrite stable context files.
8. Report:
   - completed;
   - verification performed;
   - unfinished;
   - next action;
   - context files updated.

Before making changes:

1. Read `.ai/index.md`.
2. Read `.ai/current.md`.
3. Read only the task-relevant context, ADRs, and task files.
4. Inspect `git status`, recent Git history, and existing uncommitted changes.
5. Do not modify code yet.

Then briefly report:

- project goal relevant to this task;
- current active task and status;
- constraints / ADRs that govern the work;
- existing uncommitted changes or conflicts;
- files likely involved;
- the next action you recommend.

After that, continue the requested task.

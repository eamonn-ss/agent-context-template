# New Task Prompt

Create a new task by copying `.ai/templates/TASK-000-template.md`
to `.ai/tasks/TASK-001-short-title.md` (use the next free number).

Before implementation:

1. Determine the smallest clear goal.
2. Define in-scope and out-of-scope work.
3. Identify relevant files.
4. Check existing ADRs.
5. Define measurable acceptance criteria.
6. Inspect current uncommitted changes.

Do not start implementation until the task boundary is explicit.

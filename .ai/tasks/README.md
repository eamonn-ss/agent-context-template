# Task Registry

Task naming:

```text
TASK-001-short-title.md
TASK-002-short-title.md
```

Create new tasks by copying:

```text
.ai/templates/TASK-000-template.md
```

Do not keep `*-template.md` files in this directory.

Recommended states:

- Backlog
- Ready
- In Progress
- Blocked
- Review
- Done
- Cancelled

Keep task files focused on execution state.

A task should contain:

- goal;
- scope;
- out-of-scope;
- acceptance criteria;
- relevant files;
- plan;
- verified results;
- open issues;
- next action.

For very small changes, creating a task file is optional.
